# 👑 Linux 用户与 root 权限

## root 是什么

**Linux 世界的"神"**——权限最高的超级管理员账户。类比：Windows 的 Administrator、Android 的"已 Root"、家里能开所有房间门的房东。

能做什么：读写任何文件、装删任何软件、改系统配置、管理所有用户、重启系统、**绕过所有权限检查**（系统先看"是不是 root"，是就直接放行）。

## 为什么平时不用 root？

- **开坦克买菜**：手滑敲错（如 `rm -rf /`）系统直接没，且没有任何确认提示
- **最佳实践**：平时用普通用户，需要系统级操作时 `sudo` 临时授权
- 好处：密码泄露破坏有限 + 操作有审计记录 + 行业标准（生产环境默认禁止 root 远程登录）

## 怎么判断我现在是谁？

| 方法 | 命令/标志 | 说明 |
|------|----------|------|
| 看提示符 | `#` vs `$` | `#` = root（"神之徽章"），`$` = 普通用户 |
| 直接问 | `whoami` | 打印当前用户名 |
| 看详情 | `id` | `uid=0(root)` 就是 root，root 的 uid 永远是 0 |

## 怎么切换身份？

| 命令 | 用途 | 要谁的密码 | 切到哪里 |
|------|------|-----------|---------|
| `su - 用户名` | 完全切换成另一个用户 | 目标用户密码 | 目标用户家目录 + 完整环境 |
| `sudo 命令` | 临时用 root 权限执行一条命令 | 当前用户密码 | 不切换环境 |
| `sudo -i` | 临时进入 root 环境 | 当前用户密码 | root 环境，`exit` 退回 |

> `su` 一定要带 `-`：不带的话只换身份不换环境变量和目录，容易出"命令找不到"的坑。

## 新建用户（root 的"造人"技能）

```bash
adduser deploy            # 创建用户，按提示设密码（信息可回车跳过）
usermod -aG sudo deploy   # 加入 sudo 组（CentOS 是 wheel 组）
# 验证：exit 后用 ssh deploy@公网IP 登录，跑 sudo apt update
```

用途：日常开发、专门建 `deploy` 用户跑服务（应用有漏洞也拿不到 root）、多人协作各用各的。

## pwd 显示 `/` 是为什么？

`/` 是文件系统的**根目录**（树根，所有目录从它长出），不是 root 的家目录。root 的家目录是 `/root`，普通用户在 `/home/deploy`。

## vim 编辑器的两种模式（2026-08-29）

vim 的键盘是**分工作的**，这是它和记事本最大的区别：

| 模式 | 键盘的作用 | 怎么进入 |
|------|-----------|---------|
| **普通模式** | 每个键都是指挥命令（`dd` 删整行、`u` 撤销） | 打开文件默认就是；插入模式按 `Esc` / `Ctrl+C` 退回 |
| **插入模式** | 正常打字 | 按 `a`（光标后）/ `i`（光标前）/ `o`（新起一行） |

**退出只有一个套路：先 Esc 回普通模式 → 再按目的选命令。**

| 命令 | 全称 | 干什么 | 什么时候用 |
|------|------|--------|-----------|
| `:wq` | write + quit | 保存 + 退出 | 改完了想保存，**最常用** |
| `:wq!` | write + quit + 强制 | 强制保存退出 | 只读文件、权限不足时强来 |
| `:q!` | quit + 强制 | 不保存直接走 | 改砸了，不要了 |
| `:qa!` | quit **all** + 强制 | 所有打开的文件全部不保存强退 | 开了多个文件/分屏，一次全关 |

> 类比：Esc = 放下笔、拿起遥控器。不放下笔（还在插入模式）就按遥控器，`:qa!` 会被当成普通字符**写进文件正文**！
>
> `Esc` 和 `Ctrl+C` 效果等价——云服务器教程教 Esc、WSL 教程教 Ctrl+C，是一回事。

**避坑：标准写法是 `:wq` 不是 `:qw`**（先 w 存盘、后 q 关机，顺序不能反；`:qw` 会报 `Trailing characters`）。

### vi 和 vim 的区别

- `vi` = 老祖宗（1976 年），几乎所有 Linux 发行版**自带**
- `vim` = Vi IMproved（增强版），语法高亮、多级撤销、插件系统，一般要 `apt install vim` 手动装
- 云服务器（装过 vim）用 `vim`，WSL（Ubuntu 默认只带 vi）用 `vi` —— 日常 `:wq`、`:q!` 这些退出命令**两者完全一样**
- 提示：迷你版 vi 里方向键偶尔会变成 ABCD 乱码，这是它功能不全的表现，装个完整版 vim 就好了
