# 常见错误记录

> 记录遇到的错误和解决方案。

| 日期       | 错误                                        | 原因                                          | 解决                                                                           |
| ---------- | ------------------------------------------- | --------------------------------------------- | ------------------------------------------------------------------------------ |
| 2026-08-11 | `NameError: name 'random' is not defined` | 用了`random` 模块，但忘了 `import random` | 文件最上面加一行`import random`；记不住就用口诀：**"用模块先 import"** |
| 2026-08-18 | 以为 `b = a` 是复制列表，结果改 `b` 时 `a` 也变了 | `b = a` 只是多配了一把"钥匙"，`a` 和 `b` 指向**同一个对象**（共用一栋"房"） | 想复制独立列表用 `b = a.copy()` 或 `b = a[:]`；口诀：**"=" 只配钥匙，不盖房子** |
| 2026-08-18 | 第一次见 `%` 符号不知道是啥 | `%` 是**取余数**运算符：`7 % 3` 结果是 1（7 ÷ 3 余 1） | `i % 2 == 0` 表示 i 是**偶数**（能被 2 整除）；`i % 2 == 1` 表示 i 是**奇数**；记住口诀：**"取余看整除后剩多少"** |
| 2026-08-27 | 搞半天没明白**余数**是啥，以为是小数的"小数点后一位" | 余数 ≠ 小数点后一位。余数是"**分不完剩下的整数**"：12 个苹果分 5 人，每人 2 个发了 10 个，剩 2 个 → 余数是 2 | 余数 = 总数 - 商 × 除数；生活例子：**分苹果**（剩篮子里） / **数手指**（数到 12 在第三轮第 2 个手指） |
| 2026-08-27 | 以为 `520.0` 是"定点数" | `520.0` 就是**普通浮点数**（带小数点就是 float），**不是定点数**；Python 里根本没有"定点数"这个类型，它只是个概念，用 `Decimal` 模拟 | 带小数点 `.0` 就是浮点数；"定点数"概念 → Python 用 `Decimal` 实现 |
| 2026-08-27 | 以为 `abs(1+3j)` 是"绝对值"结果 | 复数没有"正负"，`abs()` 对复数算的是**模**（到原点的距离），用勾股定理：√(1²+3²) = √10 ≈ 3.162 | 记住：**`abs` 本质 = "离 0 有多远"**。整数去负号，复数算距离（勾股定理），结果永远 ≥ 0 |
| 2026-08-27 | `complex(4, 3+4j)` 输出 `3j`，完全想不通 | `complex(real, imag)` 其实是 `real + imag * 1j`。当 imag 本身也是复数时，会先算 `(3+4j) * j = 3j + 4j² = 3j - 4`，再和 real=4 相加 → `4 + (-4 + 3j) = 3j` | **不要给 `complex()` 的 imag 位置传复数**，正常人不会这么用。记住：`complex(a, b) = a + b*j`，其中 `j² = -1` |
