# 常见错误记录

> 记录遇到的错误和解决方案。

| 日期       | 错误                                        | 原因                                          | 解决                                                                           |
| ---------- | ------------------------------------------- | --------------------------------------------- | ------------------------------------------------------------------------------ |
| 2026-08-11 | `NameError: name 'random' is not defined` | 用了`random` 模块，但忘了 `import random` | 文件最上面加一行`import random`；记不住就用口诀：**"用模块先 import"** |
| 2026-08-18 | 以为 `b = a` 是复制列表，结果改 `b` 时 `a` 也变了 | `b = a` 只是多配了一把"钥匙"，`a` 和 `b` 指向**同一个对象**（共用一栋"房"） | 想复制独立列表用 `b = a.copy()` 或 `b = a[:]`；口诀：**"=" 只配钥匙，不盖房子** |
| 2026-08-18 | 第一次见 `%` 符号不知道是啥 | `%` 是**取余数**运算符：`7 % 3` 结果是 1（7 ÷ 3 余 1） | `i % 2 == 0` 表示 i 是**偶数**（能被 2 整除）；`i % 2 == 1` 表示 i 是**奇数**；记住口诀：**"取余看整除后剩多少"** |
