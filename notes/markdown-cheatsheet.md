# Markdown 速成笔记

> 搬运自 Obsidian 知识库 · 整理自与 DeepSeek 的对话（2026年5月）
> 5 分钟学会 80% 常用语法

## 摘要

Markdown 的核心魅力在于"写的时候像纯文本，渲染出来像网页"。最常用的 5 种语法（标题、链接、表格、代码块、列表）可在 5 分钟内掌握。关键技巧：用 AI 帮你生成复杂表格、表格上方必须空一行、Emoji 可直接用在 Markdown 中。

---

## 一、5 分钟速成

| 你想要的效果 | 你写 | 渲染后 |
|------------|------|--------|
| **标题** | `# 一级标题` → `###### 六级标题` | 大字、加粗、分层 |
| **链接** | `[DeepSeek](https://chat.deepseek.com)` | 可点击的蓝色文字 |
| **表格** | `\| 名称 \| 用途 \|`（后跟分隔行）| 规整的表格 |
| **代码块** | ` ```python ` ... ` ``` ` | 带高亮的代码 |
| **列表** | `- 项目一` | 带圆点的列表 |

## 二、最容易踩的坑

### 表格上面必须空一行
```markdown
这是一段文字。

| 列1 | 列2 |    ← ✅ 正确，上面有空行
|:---|:---|
| 内容 | 内容 |

这是一段文字。| 列1 | 列2 |   ← ❌ 错误，没空行不渲染
```

### Markdown 小技巧
| 元素 | 必须做的 |
|------|---------|
| 表格 | 上面**空一行**，否则不渲染 |
| 列表 | 上面空一行（推荐）|
| 代码块 | 上面空一行，下面空一行 |
| 标题 | 上面空两行（排版更舒服）|

## 三、Emoji 用法

- 直接复制粘贴：😄 🎉 📚 🛠️ 🐳
- Windows 快捷键：`Win + .` 弹出 Emoji 面板
- Markdown 渲染后直接显示，不需要图片上传

## 四、笔记本电脑竖线（|）输入

- **正确姿势**：`Shift` + `\`（Backspace 下面，Enter 上面的键）
- 如果出 `、`，说明输入法还是中文模式，切英文
- 也可以用 AI 生成："帮我生成一个 Markdown 表格..."

## 五、简单练习模板

```markdown
# 📚 我的 AI 学习笔记
## 🛠️ 常用工具
- 🐳 Docker
- 🤖 Dify
- 📦 GitHub
## ✅ 待办
- [ ] 图纸 Agent
- [ ] 考研复习
```
