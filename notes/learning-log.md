### 复习巩固（以问答 + 实战方式）

今天没有学新内容，重点是把已学知识通过"问答 + 写代码"的方式彻底巩固。

#### 复习板块

- **`==` vs `is`**：`==` 比较值（内容），`is` 比较身份（内存地址 / id）；`a = [1,2,3]`、`b = [1,2,3]` 时 `a == b` 为 True 但 `a is b` 为 False
- **变量赋值 `=` vs `copy()`**：`b = a` 只是"多配一把钥匙"（同一栋房），改 b 会影响 a；`b = a.copy()` 才是"复制一栋独立房"
- **`while` 条件 + `break` 顺序陷阱**：`while counts > 0` 的含义是"只要 counts 大于 0 就继续"；`break` 只能拦下"它之后还没执行的代码"，拦不住"它之前已经执行的代码"——代码顺序一变结果就变
- **`for` 遍历**：`in` 后面放什么就一个一个拆什么——列表拿元素、字符串拿字符、`range` 拿编号
- **`range(n)`**：从 0 数到 n-1，共 n 个数；`range(1, 11)` 可以指定从 1 开始数到 10
- **`continue`**：跳过本次循环，进入下一次（和 `break` 的"全停"对比记忆）
- **黄金组合**：`for i in range(n)` + `列表[i]` = 按编号逐个取列表元素（`enumerate` 的底层原理）

#### 新学知识点

- **`%` 取余数**：`7 % 3 = 1`；`i % 2 == 0` 判断偶数，`i % 3 == 0` 判断 3 的倍数
- **`!=` 不等于**：和 `==` 相反，`i != 0` 就是"i 不等于 0"
- **`and` 并且**：两边条件都成立才算真，如 `i != 0 and i % 2 == 0`
- **"过滤"思维**：方案 A 从源头避免（改 range 起始），方案 B 放进来再过滤（加条件排除）——数据分析里常用

### Day 1：函数 + 计算机基础知识（听网课 + 随堂提问）

#### 函数（第一讲）

- **函数 = 把重复动作打包成"菜谱"**，用的时候照菜谱做，不用重复写步骤
- 语法 4 要素：`def` + 函数名 + 括号 `()` + 冒号 + 缩进
- 关键规则：先定义后调用；程序从上往下顺序执行，遇到函数就"钻进菜谱执行一遍再出来"
- 函数价值 = 避免重复
- 参数 = 往菜谱里塞"食材"，同一个菜谱做不同味道

#### 数字类型 & 浮点数

- 浮点数 = 带小数点的数（int 没小数点，float 有小数点）
- **大坑**：`0.1 + 0.2` = `0.30000000000000004`，不是 0.3！因为二进制存不精确
- 实测 `0.3 < 0.1 + 0.2` 是 True
- 别用浮点数直接比相等；算钱用 Decimal；打印好看用 `round()`
- **Decimal** = 精确小数（算钱专用），要用字符串创建 `Decimal("0.1")`，传数字会带进误差
- 自己探索出两种写法：`import decimal` + `decimal.Decimal(...)` 和 `from decimal import Decimal`

#### 进制（计算机基础知识）

- 不同进制 = 不同的数数规则，区别在"满几进一"
- 电脑用二进制（0 和 1），因为电路只有通/断两个状态
- 自己推出了三进制（满3进一）、八进制（满8进一）的规律！
- Python 写法：`0b` 二进制、`0o` 八进制、`0x` 十六进制

#### import 与模块思维

- `import` = 把工具箱搬进来；不 import 会报 `NameError`
- 两种导入方式：`import 工具箱`（写前缀）vs `from 工具箱 import 工具`（不写前缀）
- `decimal`（小写）= 模块/工具箱；`Decimal`（大写）= 工具/类
- **模块思维口诀**：搬箱子（import）→ 拿工具（模块.工具）→ 干活 → 存结果
- 一个模块有很多工具（random 有 randint/choice/shuffle…）
