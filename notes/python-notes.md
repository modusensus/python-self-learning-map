## 基础语法要点

### 变量

**变量就是给数据起个名字，方便后面拿来用。**

```python
# 把数字 9 存到变量 answer 里
answer = 9

# 后面直接用 answer 就行
print(answer)       # 输出 9
print(answer + 1)   # 输出 10
```

**变量命名规则：**

- 只能包含字母、数字、下划线（`_`）
- 不能以数字开头
- 不能是 Python 关键字（如 `print`、`if`、`for` 等）
- 区分大小写（`Name` 和 `name` 是两个变量）

**常见命名风格：**

- **蛇形命名**（推荐）：`my_name`、`guess_number` —— 变量、函数用
- **驼峰命名**：`myName`（小驼峰）、`MyName`（大驼峰，类名用）
- **全大写**：`PI`、`MAX_SCORE` —— 常量用

**Python 关键字列表（不能用做变量名）：**

```python
import keyword
print(keyword.kwlist)
# ['False', 'None', 'True', 'and', 'as', 'assert', 'async', ...]
```

**两个补充：**

- 变量名长度不限，但别太长，方便阅读即可
- 支持中文命名，但**不推荐**在正式项目中使用

**常见变量名类型：**

| 类型   | 例子                                              | 说明             |
| ------ | ------------------------------------------------- | ---------------- |
| 缩写   | `temp`, `num`, `max`, `min`, `sum`      | 临时变量、数字等 |
| 全称   | `user_input`, `guess_number`, `total_score` | 见名知意，最推荐 |
| 通用名 | `i`, `j`, `k`                               | 循环计数器       |
| 单字母 | `x`, `y`, `n`, `s`                        | 数学公式或临时用 |

**命名原则：**

- **见名知意**：看到名字就知道存了什么
- **不要太长**：`the_number_the_user_guessed` 太啰嗦，`guess` 就够了
- **保持一致**：全用英文，不要中英文混用

**常用命名场景：**

| 场景     | 推荐变量名                              |
| -------- | --------------------------------------- |
| 用户输入 | `input` / `user_input` / `text`   |
| 数字     | `num` / `count` / `total` / `n` |
| 结果     | `result` / `output` / `answer`    |
| 临时存   | `temp` / `tmp`                      |
| 列表     | `items` / `data`                    |
| 标志     | `flag` / `is_done` / `has_error`  |

**代码示例：**

```python
# 用户输入
user_input = input("请输入你的名字：")
age_text = input("请输入年龄：")

# 数字
count = 0                     # 计数器
total = 100 + 50              # 总和
num = int(input("猜数字："))   # 数字

# 结果
result = (5 + 3) * 2          # 计算结果
answer = "猜对了！"            # 答案

# 临时存
temp = x                      # 交换值时暂存
tmp = name.lower()            # 临时处理后的值

# 列表
items = ["苹果", "香蕉", "橘子"]   # 一组东西
data = [1, 2, 3, 4, 5]             # 数据

# 标志
is_done = True               # 是否完成
has_error = False            # 是否有错误
flag = True                  # 通用标志
```

**常见用法：**

```python
# 存用户输入
guess = input("猜一个数字：")

# 存计算结果
total = 10 + 20

# 变量可以重新赋值
x = 5
x = x + 1  # 现在 x 是 6
```

**变量交换值：**

用临时变量交换（三步法）：

```python
x = 5
y = 9
z = x    # 先把 x 存到临时变量 z
x = y    # x 被 y 覆盖
y = z    # y 从 z 拿回原来的 x
print(x, y)  # 9 5
```

Python 一行交换（推荐）：

```python
x, y = y, x   # 直接交换，不用临时变量
```

### 字符串

**字符串就是一段文本，用引号包起来：**

```python
"你好"
'hello'
"123"     # 包了引号就是文本，不是数字
```

**变量 vs 字符串：**

- **变量**是容器（标签），可以指向不同类型的数据
- **字符串**是数据本身（内容），是一段固定的文本

```python
name = "小明"   # name 是变量，"小明" 是字符串
name = "小红"   # 同一个变量可以换内容
name = 123      # 变量也可以指向数字
```

**字符串常见操作：**

```python
# 拼接
"你好" + "Python"   # "你好Python"

# 重复
"哈" * 3            # "哈哈哈"

# 取长度
len("hello")        # 5

# 索引（从0开始）
"hello"[0]          # "h"
"hello"[1:3]        # "el"（切片）
```

**单引号 vs 双引号：**

两种引号是为了方便在字符串里包含引号本身：

```python
print("I'm a student")    # 双引号包单引号
print('他说："你好"')      # 单引号包双引号
```

**转义字符：**

用 `\` 给特殊字符换个意思，解决引号冲突等问题：

| 写法   | 含义          | 示例                  |
| ------ | ------------- | --------------------- |
| `\'` | 单引号        | `'I\'m OK'`         |
| `\"` | 双引号        | `"他说\"好\"`       |
| `\\` | 反斜杠本身    | `"C:\\Users\\name"` |
| `\n` | 换行          | `"第一行\n第二行"`  |
| `\t` | 制表符（Tab） | `"a\tb"`            |

```python
print("第一行\n第二行")
# 输出：
# 第一行
# 第二行
```

**原始字符串（raw string）：**

字符串前加 `r`，里面的反斜杠不转义，适合写路径：

```python
path = r"C:\Users\name\Desktop"    # 不用写双反斜杠
```

**实用技巧：** 外面用单引号时，里面的双引号不需要转义，反之亦然：

```python
# ❌ 多余转义
print('\"Life is short\"')   # 外面是单引号，" 不需要转义

# ✅ 正确写法
print('"Life is short"')     # 简洁
print("It's a book")         # 外面双引号，里面单引号不用转
```

**打印文件路径的三种方式：**

```python
# 方式一：双反斜杠 \\（转义）
print("C:\\Users\\name\\Desktop")

# 方式二：原始字符串 r""（推荐）
print(r"C:\Users\name\Desktop")

# 方式三：正斜杠 /（Windows 也支持）
print("C:/Users/name/Desktop")
```

⚠️ 注意：原始字符串不能以反斜杠结尾，会报错：

```python
r"C:\Users\"  # ❌ 语法错误，引号被转义了
```

**长字符串的四种写法：**

```python
# 1. 三引号（保留换行，适合多行文本）
print("""人生苦短，
我用Python。""")

# 三引号也可以用单引号，效果一样
print('''人生苦短，
我用Python。''')

# 2. 括号隐式连接（推荐，不保留换行）
print("人生苦短，"
      "我用Python。"
      "学就完事了！")

# 3. 反斜杠行连接（旧写法，不保留换行）
print("人生苦短，\
      我用Python。")

# 4. 变量拼接（动态构建）
s = "人生苦短，"
s += "我用Python。"
print(s)
```

### 类型转换 — int()

**`int()` 把其他类型转成整数。**

**四种用法：**

```python
# 1. 字符串→整数（最常用）
int("42")      # 42
int(" 9 ")     # 9（自动去空格）

# 2. 浮点数→整数（直接截断，不四舍五入）
int(3.99)      # 3
int(-3.7)      # -3（向零取整）

# 3. 指定进制转换
int("1010", 2)    # 10（二进制→十进制）
int("FF", 16)     # 255（十六进制→十进制）

# 4. 不传参数
int()   # 0
```

**常见错误：**

```python
int("3.14")    # ❌ 字符串里有小数点
int("nine")    # ❌ 不是数字格式
```

### 比较运算符

**比较两个值的关系，结果只有 `True` 或 `False`。**

| 运算符     | 含义           | 示例           | 结果                 |
| ---------- | -------------- | -------------- | -------------------- |
| `==`     | 等于           | `5 == 5`     | `True`             |
| `!=`     | 不等于         | `5 != 3`     | `True`             |
| `>`      | 大于           | `5 > 3`      | `True`             |
| `<`      | 小于           | `5 < 3`      | `False`            |
| `>=`     | 大于等于       | `5 >= 5`     | `True`             |
| `<=`     | 小于等于       | `5 <= 3`     | `False`            |
| `is`     | 是同一个对象   | `a is b`     | `True` / `False` |
| `is not` | 不是同一个对象 | `a is not b` | `True` / `False` |

**注意：**

- `=` 是赋值，`==` 是比较，不要搞混
- `==`、`!=`、`>=`、`<=` 是整体，中间不能加空格
- 运算符两边推荐各加一个空格，便于阅读：`guess == 9`

### `is` 和 `is not`

**`==` 比较值（内容），`is` 比较身份（是不是同一个对象）。**

```python
a = [1, 2, 3]
b = [1, 2, 3]

a == b    # True  → 内容一样
a is b    # False → 不是同一个对象
```

**推荐用法：判断 `None`、`True`、`False` 时用 `is`：**

```python
if x is None:      # ✅ 推荐
if x is not None:  # ✅ 推荐
if x is True:      # ✅
```

**不要用 `is` 比较数字和字符串，用 `==`：**

```python
a == b    # ✅ 比较数字/字符串
a is b    # ❌ 可能出意外（Python 缓存机制导致结果不稳定）
```

### 嵌套

**嵌套就是一个结构里面再套一个同样的结构，像套娃一样。**

**`if` 嵌套：**

```python
score = 85

if score >= 60:               # 外层：及格了？
    print("及格了")
    if score >= 90:           # 内层：优秀不？
        print("优秀！")
    elif score >= 80:
        print("良好")
    else:
        print("还行")
else:
    print("不及格")
```

**常见嵌套类型：**

| 类型         | 例子                          | 说明             |
| ------------ | ----------------------------- | ---------------- |
| `if` 嵌套  | `if...: if...:`             | 条件里再判断条件 |
| 循环嵌套     | `for x in...: for y in...:` | 循环里再套循环   |
| 数据结构嵌套 | `[[1,2], [3,4]]`            | 列表里放列表     |

**注意：** 嵌套越多缩进越深，一般不超过 3 层，否则可读性变差。

### 循环结构

**循环让代码重复执行，不用一遍遍手写。Python 有两种：`while` 和 `for`。**

#### `while` 循环 — 条件满足就一直做

```python
guess = 0
answer = 9

while guess != answer:
    guess = int(input("猜一个数字："))

print("猜对了！")
```

- `while` 后面跟条件，条件为 `True` 就一直执行
- 条件变成 `False` 就退出

#### `for` 循环 — 遍历一个序列

```python
# 遍历字符串
for char in "Python":
    print(char)   # 逐个输出 P y t h o n

# 遍历列表
for fruit in ["苹果", "香蕉", "橘子"]:
    print(fruit)

# 配合 range() 产生数字范围
for i in range(5):        # 0,1,2,3,4
    print(i)

for i in range(1, 10):    # 1,2,3,...,9
    print(i)
```

- `for` 把一个序列里的东西挨个取出来用
- `range(n)` 生成 0 到 n-1 的数字
- `range(start, stop)` 生成 start 到 stop-1

#### 控制循环的关键词

| 关键词       | 作用                           | 示例               |
| ------------ | ------------------------------ | ------------------ |
| `break`    | **立即结束**整个循环     | 猜对了就不继续了   |
| `continue` | **跳过本次**，进入下一次 | 遇到不合法的值跳过 |

```python
# break 示例
for i in range(10):
    if i == 5:
        break      # 到 5 就停
    print(i)       # 输出 0 1 2 3 4

# continue 示例
for i in range(5):
    if i == 2:
        continue   # 跳过 2
    print(i)       # 输出 0 1 3 4
```

#### `break` 的用途

**`break` 是"立即跳出循环"，不是让条件自然结束，而是"立刻走人"。**

**常见用途：**

| 用途               | 说明                           | 示例                   |
| ------------------ | ------------------------------ | ---------------------- |
| 提前结束循环       | 条件满足时没必要继续了         | 猜对了就不继续猜       |
| 配合`while True` | 无限循环，等某个条件触发才退出 | 游戏菜单"按 0 退出"    |
| 配合`for` 循环   | 找到了目标，后面的不用再遍历了 | 在列表里找到某个值就停 |

**`break` vs 修改计数器：**

```python
# break — 立即跳出，后面的代码不执行
counts = 4
while counts > 0:
    if guess == 9:
        break           # ← 立即跳出循环
    print("还在循环中")  # ← 不会执行
    counts -= 1

# 修改计数器 — 当前轮次还会跑完
counts = 4
while counts > 0:
    if guess == 9:
        counts -= 4     # ← counts 归零，但本轮还没结束
    print("还在循环中")  # ← 这行还会执行
    counts -= 1          # ← 这行也会执行
```

**结论：** 想立即退出用 `break`，更直接、更清晰。

#### 小提示

- `!=` 是**不等于**，`while guess != answer` 意思是"当 guess 不等于 answer 时就一直做"
- `if`、`while`、`for` 后面都要加冒号 **`:`**，表示"后面跟着的缩进代码块属于我"
- Python 用冒号 + 缩进表示代码块，其他语言（如 JavaScript、C）用花括号 `{}`

#### 计数器循环 — 防止死循环

**每次循环把计数器减 1，条件不满足时循环自动结束。**

```python
counts = 4
while counts > 0:
    print("I love you!")
    counts = counts - 1    # 每次减 1
```

执行过程：

| 轮次 | counts | counts > 0？ | 打印        | 执行后 counts |
| ---- | ------ | ------------ | ----------- | ------------- |
| 1    | 4      | True         | I love you! | 3             |
| 2    | 3      | True         | I love you! | 2             |
| 3    | 2      | True         | I love you! | 1             |
| 4    | 1      | True         | I love you! | 0             |
| 5    | 0      | False        | —          | 循环结束      |

**如果不写 `counts = counts - 1`，counts 永远是 4，条件永远为 True，就会变成死循环，程序停不下来。**

**简写：**

```python
counts -= 1    # 等同于 counts = counts - 1
```

类似的简写还有：

| 简写       | 等同于        | 含义 |
| ---------- | ------------- | ---- |
| `x += 1` | `x = x + 1` | 加   |
| `x -= 1` | `x = x - 1` | 减   |
| `x *= 2` | `x = x * 2` | 乘   |
| `x /= 2` | `x = x / 2` | 除   |

### 缩进 — 用空格表示代码归属

**Python 用缩进来表示"这段代码属于谁"，而不是用花括号 `{}`。**

**基本规则：** 同一代码块里的行，缩进必须一致（一般用 4 个空格）。

```python
if guess == 9:
    print("猜对了")       # ← 缩进 4 空格，属于 if
    print("好厉害")       # ← 同样缩进，继续属于 if
print("游戏结束")         # ← 没缩进，不属于 if
```

**常见缩进场景：**

| 场景                         | 缩进的内容             | 示例                                          |
| ---------------------------- | ---------------------- | --------------------------------------------- |
| `if` / `elif` / `else` | 条件成立时要执行的代码 | `if` 下面的 `print`                       |
| `while` / `for`          | 循环里要重复执行的代码 | `while` 下面的 `print` 和 `counts -= 1` |
| `def`（函数）              | 函数里的所有代码       | 后续学习                                      |
| `class`（类）              | 类里的所有代码         | 后续学习                                      |

**嵌套缩进（越内层缩进越多）：**

```python
if guess == 9:
    print("猜对了")
else:
    print("猜错了")
    if guess < 9:       # ← 4 空格，属于 else
        print("小了")   # ← 8 空格，属于内层 if
    else:
        print("大了")   # ← 8 空格，属于内层 else
print("结束")           # ← 没缩进，谁都不属于
```

**注意：**

- 缩进一般用 **4 个空格**（不要混用 Tab 和空格，会报错）
- 不缩进或缩进不一致会报 `IndentationError`

### 空行 — 分隔不同逻辑

**空行不是语法要求，而是为了让代码更好读，像作文的自然段。**

```python
# 第一部分：用户输入
name = input("名字：")
age = input("年龄：")

# 第二部分：处理
if int(age) >= 18:
    print(f"{name} 是成年人")
```

**官方规范（PEP 8）建议：**

- 不同逻辑块之间空 **1 行**
- 函数 / 类定义前后空 **2 行**

```python
def hello():
    print("hi")


class Person:
    pass
```

**Python 解释器会忽略空行，纯粹是给人看的。**

## 常用标准库

### random — 随机数模块

**Python 内置的"随机数"模块，用来生成随机数字、随机选择等。**

**先导入才能用：**

```python
import random
```

**常用功能：**

| 函数                     | 作用                              | 示例                                         |
| ------------------------ | --------------------------------- | -------------------------------------------- |
| `random.randint(a, b)` | 随机整数（**包含** a 和 b） | `random.randint(1, 10)` → 1~10 里的一个数 |
| `random.random()`      | 0~1 之间的随机小数                | `random.random()` → 0.37                  |
| `random.choice(列表)`  | 从列表里随机选一个                | `random.choice(["石头", "剪刀", "布"])`    |
| `random.shuffle(列表)` | 打乱列表顺序                      | 洗牌                                         |

**猜数字游戏中的应用：**

```python
import random

answer = random.randint(1, 100)   # 让电脑随机出一个 1~100 的数字
```

这样每次运行游戏，答案都不一样，不用写死数字。

**小知识 — 伪随机：**

`random` 生成的是**伪随机**——基于一个初始种子（seed）算出来的，看起来随机但实际可复现：

```python
random.seed(42)      # 设了种子后，每次生成的序列都一样
```

日常使用不用管这个细节，直接调用就行。

**进阶 — 保存 / 恢复随机状态：**

`getstate()` 把随机数生成器的**内部状态"拍照"存下来**，`setstate()` 恢复到拍照那一刻。主要用于**调试复现**（某个随机数导致 bug，想重现同样的情况）和**实验对比**（让不同代码用同一串随机数）。

```python
import random

state = random.getstate()          # 📸 保存当前状态
print(random.randint(1, 100))      # 随机出一个数 A
random.setstate(state)             # ⏪ 恢复到拍照那一刻
print(random.randint(1, 100))      # 又随机出 A（和上面一样）
```

> 现在用不上，先混个眼熟。等以后需要"重现同样的随机结果"时自然会想到它。

#### 实战案例：验证"时光倒流"（2026-08-11）

**完整代码：**

```python
import random  # 1. 导入 random 工具箱

# 2. 先随机一个数（练习 print 输出）
print(random.randint(1, 10))

# 3. 保存当前随机状态到 x
x = random.getstate()   # 📸 "随机到哪一步了"拍照存进 x
print(x)                # 打印状态（一堆内部数据，看不懂很正常）

# 4. 在保存状态之后，再随机一个数
print(random.randint(1, 10))   # ← 记下这个数字 B

# 5. 恢复之前保存的状态（时光倒流 ⏪）
random.setstate(x)

# 6. 恢复后再随机一个数
print(random.randint(1, 10))   # ← 应该和 B 一模一样！
```

**运行输出：**

```
4                          ← 第 2 步：随便随机的一个数
(3, (...超长数字串...), None)  ← 第 3 步：打印的状态（内部数据）
2                          ← 第 4 步：保存状态后，随机出的数字 B = 2
2                          ← 第 6 步：恢复状态后，又随机出的数字 = 2
```

**讲解：**

- 第 4 步和第 6 步结果**都是 2** —— 因为 `setstate(x)` 把状态恢复到了"拍照"那一刻，随机数生成器"重新播放"，所以又出了同一个数字
- 第 3 步打印的一大串数字就是随机数生成器的**内部状态**，不用看懂
- 这个案例同时练习了：`import`、`print`、`getstate`/`setstate`，还踩了一次 `NameError` 的坑

### print 输出 — 计算不等于显示

**Python 代码"算出来"和"显示出来"是两回事。**

```python
# 只做计算 —— 结果被"吞掉"了，屏幕上没有东西
random.randint(10, 1000)

# 计算 + 输出 —— 结果显示出来
print(random.randint(10, 1000))
```

**关键点：** 在 `.py` 脚本文件里，Python 只负责算，不负责显示。**想看到结果，就必须 `print()`。**

**为什么网课老师不写 print？**

因为老师用的是 **Jupyter Notebook** 或**交互式终端（REPL）**，这种环境会**自动显示最后一个表达式的值**，看起来像是"不用 print"，其实是环境替他打了 print。

| 环境             | 要不要写 print   | 说明                                  |
| ---------------- | ---------------- | ------------------------------------- |
| `.py` 脚本文件 | **必须写** | 只算不显示，想看到结果必须`print()` |
| Jupyter / 交互式 | 不用写也行       | 自动显示最后一个表达式的值            |
| VS Code 运行 .py | **必须写** | 和脚本文件一样                        |

**print 的常见用法：**

```python
print(123)                                # 打印一个值
print("答案是", 42)                        # 打印多个值，用逗号隔开
secret = random.randint(1, 100)           # 存进变量再打印（方便后面用）
print(secret)
print(f"生成的随机数是: {secret}")          # f-string 格式化输出
```

**口诀：** 脚本里想看到结果，必须 print 才显示。
