# Python 练习项目

> 每学完一个知识点，就在这里建一个文件夹放练习代码。

## 文件夹说明

| 文件夹 | 中文名 | 内容 | 状态 |
|--------|--------|------|------|
| `guess-game/` | 猜数字游戏 | 第一个完整游戏：`random` + `while` + `if` + `break` | ✅ 已完成 |
| `paper-organizer/` | 小练习集 | 巩固 `for` / `range` / `%` / `continue` 的小练习 | ✅ 进行中 |
| `daily-report-agent/` | 日报小助手 | （待做）自动生成每日学习日报的小 Agent | 🔲 待开始 |
| `markdown-generator/` | Markdown 生成器 | （待做）把数据转成 Markdown 格式输出 | 🔲 待开始 |

## 已完成的练习文件

### guess-game/（猜数字游戏）

| 文件 | 内容 |
|------|------|
| `game.py` | 猜数字主程序：4 次机会，猜大猜小有提示 |
| `random_draft.py` | random 模块的练习草稿（getstate/setstate 时光倒流实验） |

### paper-organizer/（小练习集）

| 文件 | 内容 | 用到的知识点 |
|------|------|-------------|
| `print-even-numbers.py` | 打印 1~10 的偶数 | `for` + `range(1,11)` + `%` + `and` + `!=` |
| `skip-multiples-of-3.py` | 跳过 3 的倍数不打印 | `for` + `range` + `continue` + `%` |

## 命名规范

- 文件夹用**英文小写+连字符**（如 `guess-game`）
- 文件用**英文小写+连字符**（如 `print-even-numbers.py`）
- 不认识英文时查上面的"中文名"列就行
